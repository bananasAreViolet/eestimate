POLLSTER HOUSE EFFECTS

Pollster house effects

How each pollster's numbers tend to run above or below Eestimate's polling average, party by party.

For every individual poll, this page compares its reported number for a party against Eestimate's LOESS-smoothed polling average on that poll's date. The gap (in percentage points) is that poll's "bias" for the party: positive means the pollster reported a higher number than the average, negative means lower. Averaging that gap across a pollster's polls gives a rough house-effect estimate.

Caveat: the polling average is itself partly built from these same pollsters' numbers, so it isn't a fully independent benchmark — read this as a description of how each pollster compares to the pack, not a scored accuracy test. Figures resting on fewer than 3 matched polls are flagged as a low sample.

NOTES

Each dot below is one individual poll's bias for a party; the thicker vertical marker is the average across all of that pollster's polls. Polls are matched to the polling average on the nearest date, within a few days either way — anything further apart than that is left out rather than guessed at.

Pollster weighting on the main tracker: Norstat/ÜI (weight 0.2 per poll, published weekly), Emor/ERR (weight 1), Turu-uuringute AS (weight 0.7). See the main Eestimate page for the polling average itself.
